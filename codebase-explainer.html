How to Run ThreatIQ Locally

Backend aur Frontend ko setup aur run karne ke real commands.

🐍 Backend (FastAPI + Python 3.11)

Python dependencies install karein, environment configure karein, aur Uvicorn server start karein:

cd backend
pip install -r requirements.txt
cp .env.example .env
# GEMINI_API_KEY add karein .env mein
uvicorn main:app --reload --port 8000
⚡ Frontend (Next.js 14 + React 18)

Node dependencies install karein aur Next.js App Router development server start karein:

cd frontend
npm install
cp .env.example .env.local
npm run dev
# Open http://localhost:3000 in your browser
🔄 Reset Demo Data (Operation Shadow DB)

Agar demo database ko fresh state par reset karna ho to root se script chalayein:

# Root folder se run karein:
python reset.py
# Ya Windows batch script:
reset_data.bat
🌐 ngrok Tunneling for Live Demo

Backend ko public HTTPS URL par expose karne ke liye:

ngrok http 8000
# Generated https URL ko frontend/.env.local mein NEXT_PUBLIC_API_URL set karein
